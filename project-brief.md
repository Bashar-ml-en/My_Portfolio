# Project Brief

## Project Identity

- Project name: Machine Learning Engineer Portfolio
- Owner: Bashar

## One-Sentence Concept

A powerful professional one-page portfolio that helps hiring managers and recruiters quickly see Bashar's machine learning skills, project work, and fit for machine learning engineer roles.

## Target User

Hiring managers and recruiters reviewing candidates for machine learning engineer jobs.

## User Goal

The visitor should understand Bashar's skills, see relevant projects, judge his fit for machine learning engineer roles, and know how to contact him.

## Build Shape

Content-led site.

## Shape Confirmation

Confirmed by the learner. The main value is reading and navigating portfolio content, not creating or saving browser data.

## Version-One Success

Version one is done enough when it is a strong one-page portfolio with clear sections for intro, skills, projects, experience or background, and contact.

## Now / Later / Never

### Now

- Build a powerful professional one-page portfolio.
- Focus the message on machine learning engineer job fit.
- Show skills and projects clearly.
- Include one clear contact action for recruiters.
- Keep the scope beginner-safe for KDBM Lite.

### Later

- Add more pages if needed.
- Add more detailed case studies.
- Add a blog, downloadable resume, or live demos after version one works.

### Never

- Do not turn today's version into a large multi-page site.
- Do not add login, payments, database, backend, live API, admin system, or hidden complex features.
- Do not invent fake metrics or experience.

## Assumptions

- The portfolio will be browser-viewable and deployable to Vercel later.
- Content can use honest placeholder details where the learner still needs to provide exact project names, links, or resume details.
- The first version will prioritize clarity, recruiter usefulness, and mobile readability.

## Proof Target

GitHub plus Vercel deployment if available, with fallback proof accepted only if the trainer approves.

## Trainer / Learner Notes

- The learner wants a professional portfolio for machine learning engineer roles.
- The learner confirmed one-page scope for today.
